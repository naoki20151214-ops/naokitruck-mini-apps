What was announced? The new Leo products are at the sampling stage

On September 15, 2026, Astera Labs announced its "Leo X-Series" and "Leo 2 E-Series and P-Series" memory controller chips. These products handle memory connections for AI accelerators and the expansion and sharing of server memory capacity. According to the company, it was already providing samples to hyperscalers (very large cloud providers) at the time of the announcement. It did not announce the start of mass production or broad production deployment.Announcement

The key point this time is adding more ways to connect memory to compute devices and to allocate capacity. Besides creating a dedicated memory tier for AI working data, the products also support reusing existing DDR4 memory. From the disclosed configurations, this can be read as an effort to make better use of memory capacity already on hand. However, this alone does not mean the DRAM supply shortage will be solved. Why does AI need a path to memory?

The background is the "KV cache" used in AI inference. It stores information calculated while processing text so it can be reused in later steps. For beginners, think of it as keeping notes on intermediate calculations so the model does not have to recalculate from the start each time it decides what comes next. When handling long contexts or many sessions at once, both the space to store those notes and the path to retrieve them become important. Company technical explainer

Astera Labs explains that when the KV cache is offloaded from the GPU to CPU-side DRAM, it may compete with other CPU work for the same data path. "Bandwidth" here means the amount of data that can be moved in a given time. Even if you add more storage space, a congested path means the needed information cannot be moved fast enough. Thinking about capacity and bandwidth separately is the key to understanding this news. Company technical explainer

Leo X-Series is combined with the company's Scorpio switches to build a dedicated memory tier for the KV cache through connections such as PCIe. The aim is to ease the load concentrated on CPU-side memory. However, this is a design benefit described by the company, not independent testing showing the same effect for every AI workload. Differences between X, E, and P, and the role of CXL

Not all of the new Leo products share the same connection method or use. X-Series handles memory connections on the accelerator side, while Leo 2 E-Series and P-Series handle expansion and allocation using CXL 3.2. The published specs break down as follows. Product specifications

ProductMain rolePublished connections and features
Leo X-SeriesDedicated memory tier for AICombined with Scorpio to connect KV cache memory via PCIe and other links
Leo 2 E-SeriesMemory capacity expansionPCIe 6 x16 connection, CXL 3.2 support
Leo 2 P-SeriesMemory pooling and sharingDual-port PCIe 6 x8 connection, dynamic capacity management

"CXL" is a standard that links processors with memory and other devices, letting the connected device be used as memory and keeping data consistent. "Pooling" means managing memory capacity together and allocating it to the hosts that need it. Adding capacity to an individual server (expansion) and allocating or sharing capacity among several hosts are different functions and should be read separately. Standards body explanation, Product description

CXL 3.2 itself is not a new standard introduced this time. The CXL Consortium released it on December 3, 2024. This version strengthened monitoring of how often memory regions are accessed, as well as repair, management, and security. The standard has been developing to support operating memory while tracking how it is used and its condition, not just connecting capacity. Note that features defined in a standard are not the same as what an individual product implements. CXL 3.2 release document

From CXL expansion to sorting out your home PC's capacity and uses

After reading about the Leo products, think of shared server memory and upgrading your own PC as separate topics. First check memory use and storage space while running your study software, and then decide whether replacing parts is enough or you need a new computer. When comparing small PCs too, first match the ports, upgradability, OS, and warranty against the performance you need. Do not treat a regular PC as a substitute for CXL products; choose candidates for the separate purpose of a home study setup.

Checklist before comparing: required memory, supported OS, upgradability, and ports. Separate what you can try with your current setup from what needs an upgrade, and then pick candidates.

How does DDR4 reuse put older memory to work?

The company says Leo 2 E-Series and P-Series have four memory controllers for DDR4 or DDR5, doubling capacity and bandwidth compared with the previous generation. This is the company's own product comparison and does not mean overall AI application speed doubles. Product description

DDR4 reuse puts existing DIMMs, meaning modules carrying memory chips, to work in a new connection setup. The company says it supports reuse with features such as memory testing, health management, and automatic repair. DDR4 does not turn into DDR5, and it is a precondition to confirm that the memory is in a reusable state. Explanation of reuse

This approach offers a way to make use of existing assets, but it cannot be read as working with any DIMM. Compatible module requirements, remaining lifespan, and actual operating costs and power consumption need to be checked case by case. The published reuse support features alone are not a basis for expecting a specific cost-saving rate. Scope of published features

How to read the performance numbers, and what to check next

Astera Labs reports up to 62% shorter TTFT and up to 22% higher TPS. TTFT is the time until the first token appears, a measure of how long you wait before an answer starts. TPS is the number of tokens generated per second, a measure of how fast text is produced. A shorter initial wait and the generation speed afterward are different measures. Performance figures and test footnotes

These are results from Astera Labs' internal testing. The footnotes say the tests used an Intel GNR server, an 8-channel DDR5 configuration, a Gen 5 AI accelerator, and Qwen2.5-32B. These are maximum values under specific conditions and cannot be treated as proof from an independent body or as a performance guarantee after purchase. The effect under different setups or workloads needs to be checked separately. Test conditions in the IR version

Going forward, the focus will be when each product moves from sampling to mass production and real deployment, pricing, and specific customers. The announcement does not give enough information to judge these. On the technical side, independent performance measurements under conditions close to real workloads and the compatibility conditions for reused DDR4 will be important. This announcement can be seen as a move to tackle memory problems in the AI era from both storage capacity and connection and allocation. Supply status at announcement, Product description
