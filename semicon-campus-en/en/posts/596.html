This article is for readers who learned in Episode 28 that "games grew the GPU's parallel processing" and want to understand what CUDA changed. You can read it even if you have never written code.

CUDA is a parallel computing platform and programming model developed by NVIDIA. It made it easier to use the GPU's computing power not only for drawing graphics but also for scientific computing, data processing, and more. CUDA is not the GPU itself, and it is not a language made only for AI.

The short answer

BeforeGPUs had high computing power, but using them for anything other than images took a lot of specialized tricks.
What CUDA didIt provided a common approach and tools to hand the computing part to the GPU and run it split into many tasks.
AfterUses spread to research, simulation, data processing, and later AI.

What changed with CUDA?

GPUs developed through the huge amount of calculation needed for 3D graphics. But having high computing power is different from being easy for researchers and developers to use for any calculation they want. To do non-image work on early GPUs, you needed graphics-specific knowledge, such as making a calculation look like a drawing task.

NVIDIA announced CUDA in 2006. The official CUDA Programming Guide describes CUDA as "a general-purpose parallel computing platform and programming model." Developers could now run the overall program on the CPU while handing calculations that are easy to parallelize to the GPU.

Send data to the GPU
Run many tasks in parallel
Return results to the CPU

What CUDA opened up was the doorway from "a GPU that draws images" to "a GPU you can program for computing."

How do the CPU and GPU work together?

A CUDA program does not always run entirely on the GPU. The official guide calls the CPU and its memory the host, and the GPU and its memory the device. The app starts on the CPU, sends the needed data to the GPU, launches the work that runs on the GPU, and receives the results.

A common misunderstanding

CUDA does not make the CPU unnecessary. Actual speed is decided by the whole system, including how the calculation is split, how much data moves between the CPU and GPU, and how GPU memory is accessed.

Splitting a large job into a "grid, blocks, and threads"

In CUDA, a function that runs on the GPU is called a kernel. When a kernel is launched, many threads run the same flow of work in parallel. Threads are grouped into blocks, and blocks are arranged into a grid.

This hierarchy is not just for memorizing the names of parts inside the GPU. It is a way to express, in a program, the parallel computing design of "splitting a big job into small jobs that do not depend on each other too much."

CUDA is not "one language" but a set of tools

CUDA is not "an AI-only language called CUDA." It is a foundation that includes not only language extensions like CUDA C++, but also a runtime that hands work to the GPU, compilers, math libraries, and debugging and performance analysis tools. The official documentation also explains that it can be used from languages and APIs other than C++.

Why did it lead to AI?

AI training and inference repeat matrix calculations a huge number of times. Parts of this work are well suited to the GPU's parallel computing. With CUDA and its libraries in place, researchers and framework developers found it easier to use GPUs as a computing foundation.

However, today's AI did not come from CUDA alone. Algorithms, data, research results, GPU hardware, memory, networks, and libraries have built up to form today's AI foundation. People who use PyTorch and similar tools may benefit from CUDA-enabled libraries underneath, even without writing CUDA directly.

Does CUDA make everything faster?

Work that is hard to splitWork that often has to wait for earlier results cannot take full advantage of massive parallelism.
Work with lots of data movementWhen transfer time outweighs calculation time, the benefit of using a GPU shrinks.
Software supportYou need to implement the work for CUDA or use CUDA-enabled libraries.

Also, CUDA is NVIDIA's platform. GPUs and accelerators from other makers have their own programming environments. You need to choose based on the use case, existing software, performance, power, and cost.

Frequently asked questions about CUDA

Is CUDA a programming language?

CUDA is not the name of a single language. It is a parallel computing platform and programming model. Besides CUDA C++, it can be used from multiple languages and development environments through libraries and APIs.

Is CUDA only for AI?

No. It is used for a wide range of computing, such as scientific and engineering calculations, simulation, image processing, and data analysis. AI is one important field where CUDA is used.

Do I need an NVIDIA GPU to use CUDA?

To run CUDA code on a GPU, you need a supported NVIDIA GPU and an environment that includes drivers and so on. GPUs from other makers have different development platforms.

Are Tensor Cores and CUDA Cores the same?

No. A Tensor Core is a compute unit that efficiently performs matrix multiply-add operations. CUDA is the foundation for using the computing functions of NVIDIA GPUs, including those units, from software.
