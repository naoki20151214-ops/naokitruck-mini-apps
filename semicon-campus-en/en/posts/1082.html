Announced September 16: helping operate design software with natural language

On September 16, 2026, Lattice Semiconductor announced "Lattice Prompt," an AI design assistance tool for its small and mid-range FPGAs, and said it could be downloaded for free starting that day. The company says it connects natural-language requests to operations in its existing design software, "Lattice Radiant," and supports everything from simulation through synthesis, place and route, timing analysis, and bitstream generation. Lattice official announcement

The dates differ between documents. The top of the PDF posted on the IR site says September 17, but the announcement date in the body is September 16. On the product page, version 1.0 of the download is also dated September 17. This article treats September 16 as the announcement date. We could not confirm the reason for the difference or the exact time the download first became available. IR PDF, Product and download page

What we can confirm is the announcement that the software is available and its listing among downloads. It has moved past the stage of being only a future plan, but this is not an announcement that chips or devices designed with Prompt have completed mass production. The available features and the results gained in actual product development need to be read separately. Announcement details

What is an FPGA? A chip whose circuit configuration can be set after manufacturing

An FPGA is a chip whose internal logic circuit configuration can be set after it is manufactured. It uses ready-made circuit building blocks and connection paths to build a circuit for a specific purpose. For example, to build a circuit that counts input signals, you describe the counting behavior, assign it to internal building blocks, and decide the needed connections. The purpose of the design process is to create and verify these settings. Radiant handles everything from creating the design to analysis, debugging, and programming the chip. Radiant official materials

With this background, the role Prompt adds becomes easier to see. The existing Radiant has features such as a shared database for design information and timing analysis. Prompt is the AI assistance part that takes the user's requests and calls the processing in that design environment. It helps to think of the foundation that does the design processing and the part that assists with operation as separate. Radiant features, Prompt description

What do synthesis, place and route, and timing analysis do?

Synthesis is the step that converts the described circuit behavior into a logic circuit configuration. In the next step, mapping, that configuration is matched to the circuit resources available on the target FPGA. It is easier to understand if you think of it as turning a description like "increase the count each time an input arrives" into a concrete configuration that can be built inside the FPGA. In the technical guide, a full compile calls synthesis, mapping, place and route, and output processing in order. Prompt technical guide

Place and route is the step that decides where each part of the circuit goes inside the FPGA and how the parts are connected. Timing analysis checks whether signals arrive within the required time. Even if the circuit's connections are logically correct, it may not run at the expected speed if signals arrive late. You need to check not only whether processing finished but also whether the timing conditions were met. Radiant analysis features, Technical guide

The bitstream generated at the end is the data used to set the circuit configuration in the FPGA. Including simulation, which checks the circuit's behavior by calculation, the support this time covers multiple steps that turn a design into configuration data. However, being covered by the tool and having every design meet its requirements are separate things to evaluate. Official announcement of the support scope, Technical guide

MCP connects AI to the existing design environment

According to Lattice, Prompt connects through MCP to a large language model (LLM) chosen by the user, or to an integrated development environment (IDE) with a built-in AI agent. The items listed for free download are an MCP server and Skills, with support for Windows and Linux. The actual design processing is done by Radiant in the background. Prompt product page

MCP (Model Context Protocol) is a connection framework for giving AI applications reference information and functions they can run. In the official specification, a server provides prompt templates, context information, tools that run processing, and so on. For example, it acts as a common gateway that lets an AI, after receiving a request like "I want to move the analysis forward," call outside processing. This connection framework itself does not guarantee that a circuit is correct. MCP official specification

According to the technical guide, the MCP server and Radiant can run on separate machines, even with different operating systems. Because the environment you interact with and the environment that runs design calculations can be separated, it is meaningful as a way to connect to existing computing environments. However, this alone does not mean that all AI input and inference stays within your own equipment. Technical guide describing the runtime environment

From FPGA design assistance to public documents and using generative AI

After reading an announcement about natural-language design assistance, take notes that separate what becomes easier to operate from what designers still need to verify. Tools for reading public English documents and courses that teach generative AI for writing and summarizing are separate entry points that help your understanding. If you start FPGA exercises, check the software's supported OS, required memory, and license. General courses are not dedicated design training for Lattice products.

Checklist before comparing: supported OS, memory, CPU, storage, and license for FPGA development tools. Separate what you can try in your current setup from what needs upgrading, then choose your options.

What matters is less operating work; "10x or more" is the maker's claim

The technical focus here is connecting natural-language requests to existing design and verification steps. If AI can reduce the effort of looking up how to operate each step and running the processing, designers may find it easier to spend time checking and fixing results. This is an expectation that can be read from the announced features. It does not mean the effect has been proven in individual development projects. Prompt feature description

Lattice claims a productivity gain of 10x or more for typical design work. This figure is the maker's claim, and the referenced materials do not show reproducible comparison conditions, measurement methods, or third-party verification. From less operating time, you cannot infer that compile speed, circuit performance, or product development time all improve by 10x across the board. Official announcement on productivity

What is free, the limits, and what to watch next

What we can confirm as free is the Prompt download. Radiant's setup guide includes checking the license type, and the Prompt technical guide also asks users to watch out for concurrent-use licenses when running background processing and interactive sessions together. There is no basis for saying the LLM or IDE you use is also free, so setup costs need to be considered for the whole environment. Free download information, Radiant setup guide, Explanation of concurrent use

Also, being able to call processing with natural language does not by itself prove that a circuit meeting the requirements is complete. Besides confirming that processing finished, you need to check simulation results and timing conditions. The referenced materials give no basis for reading that Prompt unconditionally guarantees design quality or completed verification. Prompt technical guide, Radiant official materials

Going forward, cases that compare operating time, number of fixes, and verification results on the same design task will help in judging the tool. Other points to check are the specific supported combinations of Radiant, LLMs, and IDEs, the total cost of use, and where data is sent and how long it is kept. Comparisons that state these conditions clearly would make it easier to evaluate how much natural-language operating assistance helps with your own design work. What Prompt provides, Technical guide for setup and operation
