Naoki

They do. The part to check depends on whether you're short on workspace, reading from storage is slow, or the processing itself takes time.

CPU vs. memory vs. storage in 30 seconds

Here are the three key takeaways

CPU = processesRuns instructions and carries out calculations and control
Memory = work in progressTemporarily holds the data you are using right now
Storage = keepsKeeps data even after the power is off
Storage→Memory→CPU

Apps and files are saved in storage. When you use them, they are loaded into memory, and the CPU processes that data. No single part can do a computer's work on its own.

Why split the work into three roles?

You might think, "Wouldn't it be faster to put everything inside the CPU?" But memory devices involve more than speed. Capacity, price, and whether data stays when the power is off all matter.

The CPU is good at processing

It can run complex instructions, but it is not a place to store lots of photos or apps for the long term.

Memory is good at quick handoffs

It can pass data to the CPU right away, but typical main memory loses its contents when the power is off.

Storage is good at keeping data

It can hold large amounts of data, but as a workspace the CPU uses directly, it is slower than memory.

By splitting the work among fast processing, a quick workspace, and large-capacity storage, computers balance speed, capacity, and price.

Understanding the three roles with a desk analogy

Naoki

I get the roles. But I still can't picture the three working together.

Professor Owl

It's easier to see if you think of a worker, a desk, and a bookshelf.

Worker = CPU

Reads the documents and does the calculations and decisions.

Desk = memory

The workspace where the documents in use are spread out.

Bookshelf = storage

Keeps finished documents for a long time.

Naoki

If the desk is small, you have to swap documents more often. So that's what it feels like when a PC slows down from low memory.

Professor Owl

That's right. But the analogy is only a starting point for grasping the roles. In reality, data is read and written as electrical signals.

Keep the analogy and the real mechanism separate

The CPU does not think like a person, and memory is not a real desk. The CPU is a circuit that runs instructions, and memory and storage are semiconductors that hold data.

How do the three work together when you open an app?

1. StorageReads the saved app or file
→
2. MemoryHolds the data needed during work
→
3. CPURuns instructions and moves the processing forward

For example, when you open a photo editing app, the program and images are loaded from the SSD into memory. The CPU uses the data in memory to draw the screen and carry out edits.

When memory runs short, the OS also uses part of storage as a temporary overflow area. Storage is slower than main memory, so switching apps and other actions tend to become sluggish.

Deep dive: cache, DRAM, and NAND

What is the "cache" inside the CPU?

Naoki

I heard there's memory inside the CPU too. Is it the same as my PC's 16 GB of memory?

Professor Owl

It's not the same. People usually mean the cache, a small, fast memory that keeps data the CPU needs right at hand.

If the CPU had to go all the way to main memory every time it needed data, it would spend more time waiting. The cache solves this by keeping frequently used data inside or near the CPU.

The CPU also has registers inside it, but this article focuses on the cache, which people often confuse with a PC's "memory capacity."

What is DRAM in main memory?

The "16 GB memory" or "32 GB memory" in a PC's specs is main memory, mainly built with DRAM. It holds the data you are using now, such as your browser, documents, and videos.

Main memory (DRAM) basically loses its contents when the power is off. In exchange, it can pass data to and from the CPU relatively quickly.

What is NAND, the basis of storage?

NAND flash memory is non-volatile memory that keeps data even when the power is off. It is used in SSDs, USB flash drives, smartphone storage, and more.

An SSD does not work with NAND alone. It is paired with an SSD controller that manages where data is stored, spreads out writes, and corrects errors.

CacheRight next to the CPU. Small and fast
DRAMData in use. Basically erased when power is off
NANDLong-term storage. Stays even when power is off

How do they differ as semiconductors?

A CPU is a logic semiconductor that handles calculation and control. DRAM and NAND, on the other hand, are memory semiconductors focused on holding data.

Type of semiconductorExamplesMain roleRelated fields
Logic semiconductorsCPU, GPU, AI chipsCalculation, control, decisionsDesign, process, EDA, leading-edge manufacturing
Memory semiconductorsDRAM, NAND, HBMTemporary holding, storage, data supplyMemory manufacturing, materials, equipment, quality, yield improvement

Even among semiconductors, different purposes mean different structures, manufacturing processes, and inspection priorities. The differences between CPUs, DRAM, and NAND also lead to differences in companies and job types.

In the AI era, memory speed matters too

AI reads and writes huge amounts of data over and over. Even if a GPU can calculate quickly, it has to wait if the data it needs doesn't arrive.

That is why, for AI semiconductors, not only the compute chip but also the distance to memory and the amount of data that can be moved at once matter. You can dig deeper into HBM in How HBM supports AI and GPUs.

Review your CPU, memory, and storage

When your PC feels slow, compare the symptom table in this article with your usage rates and check whether the CPU, memory, or storage is falling short. If your model allows upgrades, narrow down candidates by the supported standards. If it can't be upgraded, or several parts fall short, compare that with replacing the whole computer. Thinking about speed together with the software you need, data storage, and budget makes choosing a learning setup more concrete.

Checklist before comparing: CPU, memory, and disk usage rates; whether upgrades are possible; required software and budget. Separate what you can try with your current setup from what needs replacing before choosing candidates.
